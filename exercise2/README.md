## 🔄 Exercise 2 ~ 10 minutes

Write a TypeScript method that calculates the sum of integers between a minimum and a maximum value (inclusive) using recursion :expressionless:

If the minimum value is greater than the maximum, it should return -1.

Example behavior:
- `sumRange(1, 5)` should return `15`, because 1 + 2 + 3 + 4 + 5 = 15.
- `sumRange(5, 1)` should return `-1` since min is greater than max.
